# Me Ajuda

Assistente pessoal de IA para ajudar no dia a dia.

## Status
Em desenvolvimento. Já conversa com o Gemini via API.

## Como rodar
1. Crie o ambiente virtual: `python -m venv .venv`
2. Ative: `source .venv/Scripts/activate`
3. Instale: `pip install -r requirements.txt`
4. Copie `.env.example` para `.env` e coloque sua chave
5. Rode: `python teste.py`
